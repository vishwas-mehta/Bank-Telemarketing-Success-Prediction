# **Bank Telemarketing Success Prediction**

This project predicts whether a customer will subscribe to a bank term deposit based on telemarketing campaign data. It uses machine learning techniques to analyze customer attributes, call details, and previous campaign outcomes.

---

## **📌 Kaggle Competition**

**Predict the Success of Bank Telemarketing**

---

## **📂 Project Overview**

The dataset contains information about customers contacted during marketing campaigns.  
The goal is to build a classification model that predicts the success of these campaigns.

### **Key Steps in the Notebook**
- Data loading & exploration  
- Handling missing values  
- Feature encoding and preprocessing  
- Training ML models (Logistic Regression, Random Forest, etc.)  
- Model evaluation using accuracy and classification metrics  

---

## **🧠 Machine Learning Approach**
